Masterlist

A fast, open-source browser for every FiveM and RedM server. The list refreshes automatically every few minutes, sorted by live player count, with filters for country, language and tags.

Built on a fork of the open-source fivem-serverlist-api by Zuntie, which reads the public Cfx.re server stream.
